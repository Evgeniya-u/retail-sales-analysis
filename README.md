# 📊 Retail Sales Analysis — Анализ данных о продажах

Проект по разведочному анализу данных (EDA) продаж розничного магазина с использованием Python.

## 🎯 Цель проекта

Провести анализ данных о продажах для выявления:
- Ключевых трендов и паттернов
- Наиболее прибыльных категорий товаров
- Сезонности продаж
- Корреляций между переменными

## 🛠 Использованные технологии

- **Python 3**
- **pandas** — работа с данными
- **matplotlib** — визуализация
- **seaborn** — статистические графики
- **Jupyter Notebook** — интерактивный анализ

## 📂 Структура проекта

- `README.md` — описание проекта
- `analysis.ipynb` — Jupyter Notebook с анализом
- `sales_data.csv` — датасет

## 📈 Основные этапы анализа

1. **Загрузка и первичный осмотр данных**
2. **Очистка данных** (проверка пропусков, типов данных)
3. **Визуализация распределений**
4. **Анализ по категориям**
5. **Корреляционный анализ**
6. **Выводы и рекомендации**

## 💡 Основные выводы

- Категория "Technology" генерирует 45% от общей выручки
- Выявлена сезонность: пик продаж в Q4
- Обнаружена корреляция между количеством и ценой товара
- 15% заказов убыточны — требуется дополнительный анализ
